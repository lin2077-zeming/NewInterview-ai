# 许可与来源确认记录

本目录用于存放**原始项目团队对本项目继续开发与参赛的许可确认记录**，作为 `NOTICE.md` 中"许可说明"的佐证材料。

## 需要放什么

请把下列材料的截图 / 导出文件放到本目录（可用 `.png` / `.pdf` / `.txt`）：

1. **团队许可确认** —— 与原始项目负责人（`Magic486`）沟通的聊天记录或邮件，内容需明确：
   - 同意本项目由其工程基座继续开发；
   - 确认本项目用于当前赛事**不构成重复申报**。
2. **团队分工确认** —— 明确各成员在原始项目中的贡献范围（用于申报材料中的"团队分工"说明）。
3. **有异议时的处理记录** —— 如某成员持保留意见，记录处理结果。

## 建议记录格式

```
确认人（GitHub 用户名）：
确认时间：
确认内容：
  - [ ] 同意在原始工程基座上继续开发
  - [ ] 确认本次参赛不构成跨赛道重复申报
  - [ ] 认可 NOTICE.md 中的贡献说明
附证据：<文件名>
```

## 注意

- 原始仓库未附带 License，因此**书面许可是必需的**，不能省略。
- 本目录内容属于内部佐证材料，是否随仓库公开可自行决定；但**申报材料中必须包含**。
- 如最终确认无法取得，请立即回到《项目计划书》I-01 重新评估是否更换选题。
