## 一、内容分层与来源标注

岗位内容分三类，对应题库里 `source.type` 的不同取值。**三类必须区分清楚，不得混为一谈**：

| 来源类型 | 含义 | 是否需带链接 | 本案中的使用情况 |
|---|---|---|---|
| `public-post` | **逐字引用**公开面试真题/题库 | ✅ 必须 | 106 条，见第二节来源清单 |
| `public-bank` | 公开题库批量采集 | ✅ 必须 | 仅计算机类岗位的历史题库（293 条） |
| `ai-generated` | **AI 生成**，参考公开面经题型把握风格与深度 | ❌ 不需要 | 其余全部（见第四节） |

> ⚠️ **诚实性说明**：`ai-generated` 的题目**不是**从任何来源抄来的，而是模型生成的。
> 其 `name` 字段写明「AI 批量扩写（参考公开面经题型）」，即生成时确实参考了
> 第二节日录中的真实题型作为风格锚点，但**内容本身是生成的**。
> 生成脚本见 `scripts/expand-role-questions.mjs`，prompt 与参考材料都在脚本里可查。

## 四、来源构成与生成方式

**题库 2735 道的来源构成**

| 来源类型 | 条数 | 占比 | 说明 |
|---|---|---|---|
| `ai-generated` | 2273 | 83.1% | 由 `scripts/expand-role-questions.mjs` 批量扩写，prompt 中含真实面经题型作锚点 |
| `public-bank` | 293 | 10.7% | 计算机类岗位的历史公开题库 |
| `public-post` | 106 | 3.9% | **逐字引用**的公开面试真题，全部带来源链接 |
| `project-authored` | 63 | 2.3% | 项目自编 |

**生成方式（可复现）**

```bash
node scripts/expand-role-questions.mjs --target 40   # 按目标题数批量扩写（幂等）
node scripts/merge-public-questions.mjs              # 合入逐字引用的公开真题（幂等）
pnpm roles:validate                                  # 校验
```

- 扩写脚本内置**重试机制**与**残缺 JSON 抢救**：模型偶发输出截断或含未转义引号的
  JSON 时，逐个抠出完整对象而非整批丢弃（实测首次失败 12/63，加固后 0 失败）。
- 扩写脚本的 prompt 里写了「参考真实面试题型，但不要照抄」，生成的题目标注
  `ai-generated` 并写明「参考公开面经题型」——**这是如实标注，不是包装**。

## 五、局限与待补

1. **真实面经覆盖不均**：`public-post` 集中在教育、医护、财会金融、法律公职、工程技术五类；
   商科、传媒类以生成的题目为主，尚无逐字引用的公开真题来源。
2. **面试报告样本少**：`interviewReports` 每岗 1–2 份，属于示例性质，不等于该岗位的真实面试记录。
3. **题目未经真实考生验证**：`ai-generated` 的题目用于练习与自测，其难度与真实性
   与真实面试存在偏差，不应作为唯一备考依据。
4. **公司条目为示意**：`companies` 字段描述的是该类型单位的通行招聘流程，
   并非某家单位的官方流程，具体以招聘方公告为准。
